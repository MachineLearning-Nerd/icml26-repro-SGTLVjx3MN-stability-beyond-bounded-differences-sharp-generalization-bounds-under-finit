# Evaluator-blind review

This page is populated only from a fresh downloaded candidate, beginning at
`README.md`, `logbook.json`, and `pages/index.md`. Repository knowledge and
OpenResearch logs are not accepted as substitutes.

The first review pass, fixes, and mandatory post-fix repeat are recorded in
`evidence/release/red-team-review.md`. Publication is blocked until the review
can locate, for every claim, its exact statement, assumptions, inline data,
raw evidence, code, checker, control, limitations, command, environment, Git
SHA, CPU allocation, and runtime.

[Download the recorded review](../../evidence/release/red-team-review.md).
