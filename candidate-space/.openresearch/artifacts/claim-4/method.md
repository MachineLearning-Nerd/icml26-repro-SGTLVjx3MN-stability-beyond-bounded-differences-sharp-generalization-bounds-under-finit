# Claim 4 method

The primary route is a six-step symbolic certificate for both displayed
Theorem 3.4 inequalities. It reconstructs each replace-one envelope, both
centering terms, the `q=2,p` moment inequality, and explicit constants
depending only on `p`.

An independent module imports none of the primary verifier. It validates the
certificate schema and exhaustively enumerates all binary samples for
`m=1,...,8`, three Bernoulli probabilities, and `p` in `{2,3,4}` for the
sample-mean algorithm with absolute loss. That finite enumeration is a
diagnostic, not the universal proof.

Two controls mutate the derivation. One deletes the population-risk increment,
turning the required `2 beta H` coefficient into `beta H`; the algebraic
inequality fails at `beta H=1`. The other deletes the `beta E H` shift; an
exact `m=1` Bernoulli witness has expected gap `1/2`, so the zero-bias mutation
fails.
