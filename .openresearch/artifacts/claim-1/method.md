# Claim 1 method

The primary route is a universal symbolic reconstruction, recorded as a
six-step proof certificate and audited line by line in the source note.
Executable code verifies the constant algebra across widely separated real
`p` values and checks the certificate schema.

An independent module, importing none of the primary verifier, exhaustively
enumerates every function on declared binary product grids, constructs the
minimal coordinate envelopes, and checks all tail breakpoints for several
product probabilities and `p` values. This is a diagnostic, not the universal
proof.

The negative control deletes the polynomial term. A rare Bernoulli
one-large-jump construction then has actual tail `1e-8` while the mutated pure
Gaussian term underflows far below it. The control must fail.
